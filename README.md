# InLight Bio (inlightbio.com)

Static site generated by `_build/build_site.py` (Python 3, standard library only).
InLight Bio is an independent biomedical science and biopharma deals publication.

- Edit content: `_build/data_sci.py`, `_build/data_news.py`, `_build/data_conf.py`, `_build/data_newco.py`
- Edit styles: `assets/css/en.css` (the base stylesheet is bundled with it into `assets/css/site.css` at build time)
- Build: `python3 _build/build_site.py`
- Preview: `python3 -m http.server 8000`
- Email routing: bd@inlightbio.com = NewCo matters only; contact@inlightbio.com = newsletter, reports, corrections
