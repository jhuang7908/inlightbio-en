# InLight Bio: English edition (inlightbio.com)

Static site generated by `_build/build_site.py` (Python 3, standard library only).
English edition of 前沿追踪 (inlight.therasik.com), published by Qiyuan Zhiyan (启元智研, Beijing).

- Edit content: `_build/data_news.py`, `_build/data_conf.py`, `_build/data_newco.py`
- Edit styles: `assets/css/en.css` (do not edit `base-from-zh.css`, which is a copy of the Chinese stylesheet)
- Build: `python3 _build/build_site.py`
- Preview: `python3 -m http.server 8000`
- Email routing: bd@inlightbio.com = NewCo matters only; contact@inlightbio.com = newsletter, reports, corrections
- Deployment and DNS: see DEPLOY.md
